# Вклик лендинг

Современный landing page для продукта **Вклик** на `React + Vite + TailwindCSS`.

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте локальный адрес из терминала, обычно `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```
